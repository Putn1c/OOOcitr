# Калькулятор нормативных сроков и стоимости инженерных изысканий

Веб-приложение для **ООО «ЦИТР»** (Центр инфраструктурных и транспортных решений).
Автоматизирует расчёт стоимости и нормативных сроков инженерных изысканий
по СП 47.13330.2016 на основе справочника базовых цен.

## Возможности

- Расчёт стоимости по виду изысканий, площади участка, категории сложности и региону.
- Расчёт нормативного срока выполнения работ (рабочие дни).
- Экспорт результата в Excel (.xlsx).
- Валидация ввода и юнит-тесты.

## Стек

- Python 3.10+
- Flask
- openpyxl
- pytest
